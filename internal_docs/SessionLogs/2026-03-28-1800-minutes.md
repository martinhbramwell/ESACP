- `_get_cf_token()` — decrypts `cloudflare_acme_token` from `ansible/group_vars/all.sops.yml`
- `_cf_dns_upsert()` — Cloudflare REST API (stdlib urllib, no SDK) — create/update A record
  `{hostname}.iridium.blue → {vm.wg_ip}` (WireGuard IP, public DNS, not /etc/hosts)
- Constants: `ZONE_DOMAINS` (dev/staging → iridium.blue, production → logichem.solutions),
  `CF_ZONE_ID_IRIDIUM`, `ACME_CERT_HOME_SACONSOLE`

**New pipeline steps:**
- Step 8b: Cloudflare DNS A record creation/update before differentiation
- Step 8c: Wildcard cert distribution — pipes fullchain.pem + key.pem from saconsole
  `/opt/acme-certs/iridium.blue/` to VM `/tmp/` via double SSH (soft-fail WARN if missing)

**Rewritten differentiate.sh:**
- Constants corrected: `bench_name_new = frappe-bench-{nickname}`, `site_url = {hostname}.{domain}`,
  `ERP_USER = adm` (matches Packer template)
- Section A2: `mv frappe-bench frappe-bench-{nickname}` before any bench commands (idempotent)
- Section H: `bench setup supervisor` + `supervisorctl update` added
- Sections I-K (conditional on cert available):
  - Install certs to `/etc/nginx/certs/iridium.blue/`
  - Generate nginx config from production template pattern:
    named upstreams (`frappe-{bench}-{site}`, `frappe-socketio-{bench}`),
    HTTP→HTTPS redirect, TLSv1.2/1.3, security headers (HSTS, X-Frame-Options, etc.),
    gzip, socketio proxy, DH params (2048-bit generated if absent), site enable + reload
  - Fallback: HTTP-only warning if cert not available

### Wildcard Cert *.iridium.blue — Issued and Live ✅ (commit f953b18)

Three bugs found and fixed in the `acme_sh` Ansible role during first-run:

| Bug | Cause | Fix |
|-----|-------|-----|
| `Permission denied: /home/you/.acme.sh/acme.sh` | Clone + Install tasks inherited play-level `become: yes` → installed as root | Added `become: false` to both tasks |
| `Permission denied: /root` (clone dest) | `ansible_user_dir` resolves to `/root` when facts gathered as root | Replaced all `ansible_user_dir` refs with `'/home/' + ansible_user` |
| `Interactive authentication required` on nginx reload | `systemctl reload nginx` requires polkit; `you` has NOPASSWD sudo but not polkit bypass | Changed to `sudo systemctl reload nginx` |

**Post-fix result:** `*.iridium.blue` + `iridium.blue` issued via Let's Encrypt DNS-01 (Cloudflare).
Valid: Mar 28 → Jun 26 2026. Cert files owned `you:you` at `/opt/acme-certs/iridium.blue/`.
