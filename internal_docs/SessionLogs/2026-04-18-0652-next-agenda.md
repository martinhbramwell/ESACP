## Session A procedure (the core of this session)

This session **writes infrastructure code against live state with user approval at every step**. It is not a normal feature-development session. Treat the ESACP rules that apply:

- Confirm before acting — even "quick" steps.
- No masking of errors — if a step fails, stop and investigate root cause.
- Heredocs feeding code are banned — every Python transform goes into a standalone file under `platforms/kvm/` or `tools/vm_scripts/`.
- No `sed` — Python `re.sub` / `str.replace`.

### Step outline (the user may revise before launch)

1. **Current-state capture**: record saconsole hostname, disk path, domain name, snapshot list, WG peer state on the hub, controller-side SOPS/hosts_map state. Commit as a reference note, *not* part of the rebuild script.
2. **Backup step** — write the first unit of `rebuild_saconsole.sh`: `virsh` (via SSH to toshiba) to shut down saconsole gracefully, qcow2-copy the disk to an archive location on the controller (scp or rsync pull), verify archive integrity. No destroy yet. Test with user approval. If backup succeeds, commit.
3. **Teardown step** — add the teardown unit: `virsh destroy` + `virsh undefine --remove-all-storage` on toshiba, targeting saconsole only. Leave dev VMs alone. WG/SOPS/hosts_map state on controller is NOT touched (source of truth). Test with user approval.
4. **Bootstrap replacement** — invoke `platforms/kvm/bootstrap_hub.sh` (existing, #220-parked for decomposition). Confirm the new saconsole rejoins the mesh.
5. **Mesh reattach verification** — sync_check.sh hub rows ✅, all MCPs return 200, controller can SSH to saconsole via WG. If any fail, **halt and investigate** — per rebuild_saconsole.sh contract, an incomplete rebuild should not exit 0.
6. **Capture as script**: at end of session, `platforms/kvm/rebuild_saconsole.sh` exists with the four phases as clearly-labelled sections (A: backup, B: teardown, C: bootstrap, D: verify). Keep it under ~100 lines if possible; lean on existing scripts for the heavy lifting rather than inlining.
7. **Revert path evidence**: before declaring done, verify the qcow2 archive can in principle be restored (spot-check via `qemu-img info`; do not actually restore). Document the manual restore procedure in the script's header comment.
