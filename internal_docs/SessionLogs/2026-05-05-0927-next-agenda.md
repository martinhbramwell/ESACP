**Phase 2 — Three reference frames cross-check**. For each row from Phase 1:

- **A. In any bespoke-app fixture file?** — `grep` across `BaRe/`, `ce_sri/`,
  `returnable/`, `route_planner/` `fixtures/*.json` and `fixtures/custom_scripts/`.
- **B. In any bespoke-app source tree?** — for DocTypes / Reports / Print
  Formats / Web Forms, check `<app>/<app>/{doctype,report,print_format,web_form}/<name>/`.
- **C. In stock Frappe/ERPNext source?** — `apps/frappe/`, `apps/erpnext/` on dev02.

A row that fails A, B, **and** C is a **DB-resident, undeclared
customization** — exactly the "quickee" class operator wants surfaced.

**Phase 3 — Code-side scan for things DB enumeration misses**:

- `apps/<bespoke>/<app>/hooks.py` — `doc_events`, `scheduler_events`,
  `app_include_js/css`, `doctype_js`, `override_whitelisted_methods`,
  `override_doctype_class`, `permission_query_conditions`, `boot_session`,
  `extend_bootinfo`
- `apps/<bespoke>/<app>/patches.txt` + `<app>/patches/`
- Re-run the in-place core-tree edit detector against current
  `apps/frappe/` + `apps/erpnext/` on dev02
