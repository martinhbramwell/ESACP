# Ansible — Claude Code Context

## site-kvm.yml Plays (5 total)

1. `base-all` — base config for all KVM hosts
2. `hub` — docker + observability + desktop + control_plane + mcp_grafana
3. Authorise hub pubkey on targets
4. `targets` — node_exporter + docker + mariadb + nginx_ui
5. `controller WireGuard` — runs on `hosts: localhost`, `connection: local`; does NOT inherit `group_vars/kvm.yml`; hub endpoint from `{{ controller_wg_hub_endpoint }}` (set in `group_vars/all.yml`)

## Inventory

- `inventory/kvm.yml` — generated by `tools/generate_inventory.py` from `hosts_map.yml` — do not edit directly
- `hosts_map.yml` is the single source of truth; `kvm.yml` is derived on every add/change
- Run `generate_inventory.py` after any `hosts_map.yml` change

## group_vars

- `all.yml` — alert_profile default + WireGuard network vars; `erp_user` sourced here (single source of truth)
- `kvm.yml` — SSH vars + `wg_hub_endpoint` for KVM guests (NOT used by Play 5 on localhost)
- `lab.yml` — `alert_profile: drill`; `production.yml` — `alert_profile: production` (enforced)
- `all.sops.yml` — SOPS/age encrypted: Telegram bot token, Grafana admin password

## MariaDB Role

- Uses `bytebase/dbhub:0.18.0` (NOT `MariaDB/mcp` — its main branch pulls PyTorch/CUDA ~3.5GB, breaks 20GB VMs)
- Deployed to `/opt/mariadb/`; MariaDB port 3306 Docker-internal only (not exposed); mysqld_exporter port 9104 UFW-restricted to hub (10.10.0.1)
- Credentials in `/opt/mariadb/.env` (mode 0600); compose file templated: `ansible/roles/mariadb/templates/docker-compose.mariadb.yml.j2`
- dbhub: SSE transport on port 9001 (internal 8080, `--transport http`); DSN passed via `--dsn mariadb://...` in compose command
- **mysqld_exporter v0.15.x**: `DATA_SOURCE_NAME` env var removed — use `--config.my-cnf=<absolute-path>`; file mode must be `0644` (runs as `nobody`). (GH #45)

## nginx_ui Role

- `uozi/nginx-ui:v2.3.5` bundles nginx — do NOT run a separate nginx container
- `/etc/nginx` volume must be EMPTY on first run; port 80 = nginx HTTP; port 9000 = admin UI + REST API + MCP SSE
- nginx-ui does NOT expose Prometheus metrics — rely on node_exporter for host metrics
- **Headless setup**: requires `NGINX_UI_NODE_SKIP_INSTALLATION=true` + `NGINX_UI_PREDEFINED_USER_NAME/PASSWORD` + `NGINX_UI_NODE_SECRET` — without these the container waits at `/install` and MCP is unavailable
- Credentials in the `nginx_ui` role's `.env` template (sourced from SOPS vars)

## mcp_grafana Role

- `grafana/mcp-grafana:0.11.3` on hub; deploys to `/opt/mcp-grafana/`; SSE port 8000
- Declares `observability_network` as `external: true` → reaches `grafana:3000` by container name
- Start observability stack BEFORE mcp-grafana or the network won't exist
- Endpoint: `http://10.10.0.1:8000/sse` (WireGuard peers only)

## Claude Code MCP Configuration

Add to `~/.claude/settings.json` on Mighty after VMs are up and WireGuard mesh verified:
```json
"mcpServers": {
  "grafana": { "type": "sse", "url": "http://10.10.0.1:8000/sse" },
  "mariadb-target1": { "type": "sse", "url": "http://10.10.0.3:9001/sse" },
  "mariadb-target2": { "type": "sse", "url": "http://10.10.0.4:9001/sse" },
  "nginx-target1": { "type": "sse", "url": "http://10.10.0.3:9000/mcp?node_secret=<secret>" },
  "nginx-target2": { "type": "sse", "url": "http://10.10.0.4:9000/mcp?node_secret=<secret>" }
}
```

- **GitHub MCP** (`github/github-mcp-server` v0.32.0): binary at `/usr/local/bin/github-mcp-server`; `type: stdio`; uses `gh auth token` scoped to `repo, read:org, admin:public_key, gist`. Repo: `martinhbramwell/ESACP`.
- **ERPNext MCP (future)**: `Frappe_Assistant_Core` (buildswithpaul/promantia-ai) — bench app, OAuth 2.0, 20+ tools. Alt: `rakeshgangwar/erpnext-mcp-server` (TypeScript, no bench required).
- **Cloudflare MCP**: API token must be tightly scoped (read-only where possible, zone-locked for writes) — a broad token in an MCP container is high blast-radius.

## Gotchas

- `ansible-playbook` must run with cwd=`ansible/` directory (not project root) for group_vars resolution
- `provision_kvm.py` uses `ansible_env()` helper to set `ANSIBLE_CONFIG` + `ANSIBLE_PRIVATE_KEY_FILE`
- Controller Ansible step uses `--ask-become-pass` (hasan needs sudo password on Mighty)
- `--extra-vars "@tmpfile.yml"` required for keys containing spaces (not `key=value` form — SSH pubkeys split on spaces)
