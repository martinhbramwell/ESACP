- `site_url` — used for sites-available/sites-enabled filename

## Design considerations

- **Single script** — I/J/K together are ~30 lines. No split needed.
- **Cert-absent path**: should the script fail hard or warn? The api.py template has two branches (cert present vs absent). The pipeline Stage 2 should have already placed the cert — if it's missing, that's a real problem.
- **DH param generation is slow** (~30s on dev VMs). Needs adequate timeout. Only runs once per VM — subsequent runs skip.
- **site_url and cert_dir as args**: cert_dir depends on `tls_domain` which is derived from zone. Pass as arg or derive in script?
