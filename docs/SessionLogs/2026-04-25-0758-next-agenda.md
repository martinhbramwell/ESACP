### Hypotheses ranked (from #298 issue body)

1. **Stale textbox match.** `getByRole('textbox').first()` is matching a textbox from an earlier screen (e.g., screen 2's full-name textbox left in DOM after navigation). Fix: use a more specific locator that's unique to screen 4a (e.g., `getByLabel('Company Name')`).
2. **SPA route hasn't completed.** After Industry-Next click, URL changes to `/app/setup-wizard/4` but the slide hasn't rendered. `waitForFrappeIdle` doesn't wait for SPA route completion. Fix: `await page.waitForURL('**/setup-wizard/4*', { timeout: 30_000 })` between Industry-Next click and screen-4a fill.
3. **CSS animation in flight.** Screen 4a is rendered but invisible during a slide transition; Playwright's auto-wait sees the textbox as not-visible. Fix: longer implicit wait, or `await page.waitForSelector('input[placeholder="Company Name"]', { state: 'visible' })`.

### Likely fix shape — verify before committing

Try hypothesis 2 first (decoupled from DOM specifics, smallest diff):

// ── Wizard screen 4a: Company name + abbr ──
