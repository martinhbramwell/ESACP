## Notes from Phase 8 — carry-forward

### #210 (WG peer drift) — procedural workaround is unreliable

In this session the one-liner fix worked at session start but **did NOT** clear the post-e2e drift. The hub's live WG peer list got out of sync with inventory and rerunning `--tags wireguard` didn't bring the missing peer back.

Before Phase 9's e2e step, **investigate** whether:
- The ansible WireGuard role's hub-peer template reads from the on-disk sops keys but doesn't detect that a peer is *missing* (idempotent update, not reconciliation)
- The play needs an explicit "purge + rebuild peer list" task
- Or the hub needs its wg0 config wiped + redeployed from scratch

If this can't be cleared reliably, the Phase 9 e2e will start with a broken mesh and fail for the wrong reason. Prefer to fix the procedural workaround (or #210 structurally) before running Phase 9 e2e.

### Cytoscape e2e takes ~30 min wall time on toshy

Budget accordingly. Power cycle is cheap; the slow step is app installation + restore.
